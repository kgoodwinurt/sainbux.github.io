## 2026-07-20 - [Optimizing Render-Blocking CSS and LCP Image Loading]
**Learning:** Relocating external CSS assets from the bottom of the body to the `<head>` tag coupled with a `<link rel="preconnect">` hint significantly reduces DocumentContentLoaded (DCL) even on fast local hosts. Additionally, defining explicit aspect ratios/dimensions (`width`/`height`) on Largest Contentful Paint (LCP) images in HTML rather than only CSS enables the browser to construct correct layout placeholder margins prior to asset loading, preventing Cumulative Layout Shift (CLS) and optimizing layout-shift score.
**Action:** Always preconnect to external asset CDNs before render-blocking stylesheets in `<head>`, and declare explicit physical dimensions (`width` and `height`) on critical above-the-fold media assets alongside `fetchpriority="high"`.
