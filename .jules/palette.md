## 2025-03-06 - Keyboard & Screen Reader Social Link Standardization
**Learning:** In simple, text-heavy profile/portfolio static sites, social links are often added as raw Font Awesome icon elements. Without a surrounding structural class, developers tend to rely on inline styles (e.g., inline margins) and ignore accessibility constructs (such as ARIA labels or focus-visible outlines). This makes the interface confusing for screen readers and hard to navigate for keyboard-only users. Furthermore, text-based social links on the same page can get mistakenly matched if automated scripts are run without precise element target selectors.
**Action:** Consolidate layout spacing inside a global `.social-icon` CSS class that includes clean transitions (like lift translation and WCAG-compliant color changes), ensure focus visibility matches the site's primary accent color (#007bbd), and explicitly add `aria-label` tags for screen reader compatibility. Avoid applying the class to inline text elements.
