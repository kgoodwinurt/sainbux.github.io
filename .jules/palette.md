## 2026-07-03 - Enhanced Social Media Interactivity and Accessibility
**Learning:** Icon-only social links benefit from a dedicated CSS class that combines transitions, transform-based hover states (lift), and high-contrast focus-visible outlines. This pattern ensures both visual delight and WCAG compliance without cluttering inline styles.
**Action:** Use a `.social-link` class with `transition: transform 0.3s ease, color 0.3s ease`, `aria-label`, and `focus-visible` outlines for all social media icon sets.
