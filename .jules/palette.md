# Palette Journal - Critical UX/Accessibility Learnings

This journal documents critical UX and accessibility learnings discovered during development.

## 2026-07-11 - Color Contrast Compliance for Brand Elements
**Learning:** The legacy brand color `#009fdf` used for primary buttons fails WCAG AA contrast requirements (3.1:1) against white backgrounds.
**Action:** Use `#007bbd` for interactive elements to achieve a compliant 4.54:1 contrast ratio while maintaining brand alignment.
