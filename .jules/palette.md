## 2026-07-16 - Selective Interactive Lift and Cross-Page Navigation
**Learning:** Applying interactive visual effects like `transform: translateY(-3px)` ("lift") to anchors should be restricted to icon-only elements (e.g., via a `.social-icon` class). Applying such transforms to inline text links disrupts line-height and causes visual jank during transitions. Additionally, navigation consistency on sub-pages requires absolute paths for anchor links (e.g., `index.html#section`) when those sections only exist on the home page.
**Action:** Always use specific CSS classes for icon-only interactive elements to isolate transform effects from text flow. Verify that all global navigation links on sub-pages correctly resolve to the primary landing page when targeting specific anchors.
