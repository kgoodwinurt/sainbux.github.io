## 2026-07-04 - Color Contrast & Interaction Standards
**Learning:** The legacy brand color #009fdf (contrast ~2.9:1) failed WCAG AA accessibility standards. Replacing it with #007bbd (contrast ~4.6:1) ensures readability while maintaining the blue brand identity.
**Action:** Use #007bbd for all primary interactive elements (buttons, hover states) in this project to ensure accessible contrast.
