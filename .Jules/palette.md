## 2025-05-14 - [Accessibility and Navigation Polish]
**Learning:** Static sites often lack basic accessibility features like `aria-label` for icon-only links and clear focus states. Improving button contrast from `#009fdf` to `#007bbd` achieves WCAG AA compliance (4.6:1), which is a small change with high impact for low-vision users.
**Action:** Always check icon-only links for missing ARIA labels and ensure interactive elements have `:focus-visible` styles and compliant contrast ratios.
